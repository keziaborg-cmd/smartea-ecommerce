# Marca Almara

Arquivos da logo enviados pela dona do produto (fundo transparente, margens recortadas). Esta pasta
não é servida pelo site; é a fonte pra gerar o que o site usa.

- `public/logo.png` (menu, rodapé e imagem de compartilhamento) = `almara-vertical-cor.png` com
  uma margem pequena. Pra trocar a logo do site, troque só esse arquivo.
- Fundo escuro: versões `-branca`. Impressão em uma cor: versões `-preta`.
- `almara-simbolo-cor.png` foi recortado da horizontal colorida (não veio separado). Os ícones do
  navegador (`app/icon.png`, `app/apple-icon.png`, `app/favicon.ico`) já são esse símbolo, que não
  mudou no rebrand.
